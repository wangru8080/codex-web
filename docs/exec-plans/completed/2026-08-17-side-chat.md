# 侧边聊天实现计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

## 目标

在工作区右侧面板实现与官方 Codex app 对齐的临时侧边聊天。侧聊复用主聊天的消息流和输入框，通过 Codex app-server 的 ephemeral thread fork 获得独立上下文，并在关闭时中断和取消订阅。

## 成功标准

- 现有主会话可打开一个侧边聊天标签，空态和关闭确认对齐官方截图。
- 侧聊直接复用 `ChatView` / `MessageInput`，附件、权限、模型、推理等级、发送和中断行为与主聊天一致。
- 侧聊使用 `thread/fork { ephemeral: true }`，消息、Turn 和错误只归属子线程。
- 关闭侧聊不调用 `thread/delete`；运行中的 Turn 先中断，再取消订阅。
- 普通主聊天路径不受影响，侧聊不可用或失败时显示真实协议错误。
