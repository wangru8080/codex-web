# 右侧工作区侧栏 UI 优化

状态：Release ready

## 目标

- 右上角只保留一个工作区侧栏入口。
- 首次展开显示工作区功能总览。
- Git、文件标签和多文件预览保持可用。
- 文件工作区采用左侧内容、右侧文件树的分栏布局。
- 保留文件路径、预览模式、复制、下载、添加到对话等现有能力。

## 完成项

- [x] 工作区入口收敛为单一按钮。
- [x] 增加审阅、终端占位、文件和侧边聊天占位总览。
- [x] 移除尚无实现的浏览器入口。
- [x] 文件空态与文件预览统一使用分栏布局。
- [x] 增加可点击文件路径面包屑。
- [x] 保留文件树右键菜单和文件选区操作。
- [x] 保留 Git 变更、历史、Diff 预览和提交能力。
- [x] 增强工作区左边界分隔线。

## 验证

- `npm run typecheck`：通过。
- `npm run build`：通过。
- 文件树、Git、文件预览相关定向 Vitest：通过。
- 通过 `192.168.3.12:3000` 使用浏览器验证总览、空文件、文件预览、文件树、Git 标签和侧栏边界。

## 反例 Smoke

- 未选择文件时，左侧显示“打开文件”空态，右侧文件树仍可操作。
- 选择文件后，左侧加载真实文件内容，右侧文件树保持显示。
- 非 Git 工作区显示“不是 Git 仓库”；Git 工作区显示真实变更和历史数据。
- 终端和侧边聊天没有后端实现时保持不可用，不展示伪造状态。
