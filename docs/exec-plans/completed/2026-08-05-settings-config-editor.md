# 设置配置编辑器执行计划

## 目标

在设置侧栏新增“配置”页面，使用 app-server 的文件接口编辑当前 `CODEX_HOME/config.toml`，并提供符合现有设置风格的弹窗编辑器。

## 实施步骤

- [x] 增加配置设置路由、导航项和中英文文案。
- [x] 增加配置页面及 config.toml 编辑弹窗，接入 initialize 与 fs/readFile、fs/writeFile。
- [x] 增加 UTF-8 Base64 解码辅助函数及单元覆盖。
- [x] 运行类型检查、单元测试、生产构建，并完成页面路由编译验证。
- [x] 完成验证后将执行计划移入 completed。

## 成功标准

- 设置侧栏可进入“配置”，页面文案和布局与样例一致。
- 打开按钮读取当前 app-server 使用的 `CODEX_HOME/config.toml`；保存通过 app-server 写回并自动关闭弹窗；取消不写入。
- 配置文件不存在时可从空内容开始创建，读写失败在弹窗内可见。
- 既有设置路由、类型检查、测试和构建不回归。
