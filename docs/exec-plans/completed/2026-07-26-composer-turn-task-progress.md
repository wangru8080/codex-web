# 输入框任务进度 UI 实施计划

技术交接：[输入框任务进度 UI 技术交接](../../handover/2026-07-26-composer-turn-task-progress.md)

> **执行方式：** 以官方 Codex App 截图为视觉基准，以 app-server 通知为唯一任务事实源。

**目标：** 在输入框上方并排展示文件变更与当前任务进度；点击任务进度展开清单；全部步骤完成或 Turn 结束后自动退出；执行任务不在消息流中重复展示。

**架构：** `turn/plan/updated` 进入 Turn reducer 后形成 `codex_updated_plan`；纯函数只从运行中的最新 Updated Plan 派生输入框数据；共享清单组件负责 completed、inProgress、pending 三种视觉状态。

**技术栈：** TypeScript、React、Vitest、现有 app-server reducer 与 CDP smoke。

## 约束

- 任务内容、状态与进度只能来自 `app-server.turn/plan/updated`。
- Proposed Plan 不进入执行任务浮层。
- 无计划、空计划、全部完成或终态 Turn 不显示任务进度。
- 不安装依赖，不改变文件变更与 Git 的既有事实边界。
